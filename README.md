#  Latin America Market Entry Strategy Dashboard

An executive Power BI model designed to evaluate and identify optimal market entry targets across Latin America based on customizable corporate priorities.

![Dashboard Preview](Market%20Entry%20Dashboard%20Preview.png)

---

##  Key Analytical Features
- **Min-Max Normalization:** Custom DAX measures isolating Latin American baselines for accurate, regional indicator scaling.
- **Interactive Scenario Weighting:** Allows dynamic multi-parameter analysis across 5 key strategic pillars (Talent, Logistics, Market Growth, Investment Freedom, Cost Efficiency) in real time.

---

## 📁 Repository Structure
- `Market_Entry_Framework.pbix` — Power BI Desktop model with DAX logic.
- `Market_Entry_Database.xlsx` — Structured dataset containing raw and normalized metrics.
